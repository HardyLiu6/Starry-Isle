# 泛化机制为不可妥协的设计原则

Cochrane 系统综述指出屏幕内习得的技能难以泛化到真实情境——这是 ASD 数字干预产品最常见的失败模式，也是"干预游戏"沦为"电子安抚奶嘴"的分界线。我们决定：**星屿的每个玩法必须自带至少一项泛化机制**（家长共玩环节、线下迁移小任务、真人照片素材等，四条设计对策见 docs/research/01-循证干预方法全景.md）。公益项目没有留存/时长类商业 KPI 压力，恰好有条件坚持这一"难而正确"的设计。

## Consequences

- 每个玩法的设计成本上升；"纯儿童单人闭环"的玩法在星屿不成立，家长角色是玩法的一部分。
- 每期开发的验收标准必须包含"泛化机制检查项"。
- 这是星屿区别于市面纯屏幕训练产品的立身之本，对外定位文案可以围绕它展开。
