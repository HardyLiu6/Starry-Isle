# 合规定位：对外不自称"游戏"，零收集、本地运行，不做筛查评估

依据调研（docs/research/04-合规红线清单.md）：网络游戏须版号方可运营（个人开发者无申报路径），免费无内购不豁免且有处罚先例；且"网络游戏"定性触发防沉迷——未成年人仅周五六日 20-21 时可用，对 4-8 岁目标玩家意味着产品实际不可用。疗效宣称则触碰《广告法》第 17 条与医疗器械边界。我们决定：

1. **对外传播与商店类目一律定位"孤独症儿童辅助训练工具"**（教育类目），不使用"游戏"表述；"功能游戏"仅作内部与技术文档词汇。
2. **全线禁用**"治疗、康复、疗效、数字疗法、患者"等用语；对外用"辅助训练、技能练习、亲子互动"（禁语/安全措辞全表见报告 04）。
3. **v1 零数据收集、纯本地运行**：无账号、无埋点、无第三方 SDK；进度用本地保存与导出，不做云同步。
4. **不做筛查/评估功能、不设疗程式说明**，保持在医疗器械三条件边界之外。
5. 免责声明在 README、官网、应用内首启页**三处同文**（中英模板见报告 04）。

## Consequences

- 品牌传播不能打"游戏"牌——"通过游戏的方式"这类既有文案需改写为"通过亲子共玩的互动练习"等表述；内部玩法设计品质不受影响。
- 零后端 = 零运维成本，顺带化解一半"单人维护死亡"风险（LetMeTalk 教训）。
- 未来加云同步前，必须先完成报告 04"加云功能前"7 项义务（监护人单独同意、儿童隐私政策、PIA 等）。
