# 首选干预领域为情绪识别与表达

星屿一期只做一个干预领域。依据调研（docs/research/01-循证干预方法全景.md）：在六大干预领域中，情绪识别与表达的游戏化证据最强（The Transporters、FaceSay、Emotiplay 等多项 RCT，元分析 SMD≈0.6）、玩法先例最成熟，且规模适合单人开发者做出完成度。社交互动领域证据同样强，但玩法复杂度高，定为二期扩展方向（与情绪识别是自然延伸：先认表情，再进社交情境）；生活自理（视频示范类玩法）进 backlog；感觉统合不适合屏幕化，明确排除。

## Considered Options

- **双领域并行（情绪识别 + 社交互动）**：证据都够强，但单人开发会摊薄两边深度，拒绝。
- **社交互动优先**：情境模拟类玩法开发量与设计难度远高于表情识别类，两周内不可能出可玩切片，拒绝。
- **感觉统合**：本质依赖身体与物理环境，屏幕媒介先天不适配，排除。
