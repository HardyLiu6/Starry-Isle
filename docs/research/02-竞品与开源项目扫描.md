- **调研日期**：2026-09-10
- **调研用途**：为"星屿 (Starry Isle)"（面向 4–8 岁轻中度 ASD 儿童、以情绪识别与表达为首选干预领域的公益免费开源功能游戏，单人开发）回答两个决策问题：**(A) 有没有值得复用或直接加入贡献的开源项目（避免重复造轮子）？(B) 竞品在情绪识别领域做到了什么程度、空白在哪里？**

## 给决策者的摘要（≤300 字）

**A**：全球不存在可整体复用的"ASD 情绪识别功能游戏"开源项目——GitHub 相关仓库均为百星以下、多无 License 的停更原型。可复用的是外围层：ARASAAC/Mulberry/OpenMoji 等开放图符与表情素材、Cboard/AsTeRICS Grid 等活跃开源 AAC（可集成并回馈中文化）、Antura 开源儿童游戏工程范本。星屿自建核心玩法并开源，正好填补空位。**B**：情绪识别证据高峰是 2003–2017 年学术产品（Transporters、Mind Reading、FaceSay、EmotiPlay 皆有 RCT），如今或死亡、或冻结、或转型卖内容包；现存活跃者要么是证据弱的订阅制通用特教（Otsimo、AutiSpark），要么是高门槛 VR 医疗化（Floreo）。国内头部全是"评估+课程+机构"形态，唯一长线功能游戏《星星生活乐园》核心是社交故事而非情绪。"免费开源+中文+4–8 岁+情绪核心玩法+内置泛化"无人占位。

### 1.2 国际格局解读

1. **证据与存活严重倒挂**。四个拥有 RCT 的情绪识别产品（Transporters、Mind Reading、FaceSay、EmotiPlay）全部诞生于 2003–2017 年学术圈，如今没有一个处于健康商业运营：死亡（Mind Reading）、冻结（FaceSay、EmotiPlay）、转型卖内容包（Transporters）。**"做出效果"和"活下去"是两个独立命题。**
2. **活着的产品证据弱**。Otsimo/AutiSpark/Autimo 均为订阅制"特教小游戏合集"，情绪识别只是众多内容页签之一，无临床对照证据，玩法是闪卡/配对的浅层操练。
3. **前沿在医疗化，门槛极高**。Floreo 走 FDA De Novo + VR 头显 + 治疗师监督路线；而 Akili 的结局（FDA 认证的处方游戏因支付方不埋单而 $34M 贱卖）证明重监管路线的商业风险——这反向验证了星屿"公益免费的辅助训练工具、不做医疗器械"定位（见 01 号报告）的合理性。
4. **对星屿最直接的模板是 The Transporters**：同为 4–8 岁段、纯情绪识别、有 RCT、且已验证"中文本地化 + 政府/公益基金资助免费发放"（香港模式）可行——但它是"看动画+答题"，不是交互玩法，且大陆不可免费获得。

### 2.2 国内格局解读：功能游戏是否存在？

1. **头部平台无一是游戏**。ALSOLIFE、恩启、暖星、大米和小米四家的产品形态是"评估系统 + 课程/题库 + 家长培训 + 线下机构（+ 近两年的 AI/SaaS）"，干预的执行者是家长和康复师，儿童直接面对的数字交互内容极少。行业分析也显示国内自闭症 App 以免费科普为主、近 88% 用户是监护人（[人人都是产品经理](https://www.woshipm.com/pmd/130628.html)）。
2. **真正的功能游戏只有一款长线运营**：三七互娱《星星生活乐园》（2022 至今，免费公益）。但其核心是**社交故事/生活场景**（超市、扶梯、餐厅），情绪仅是 3.0 版本新增的"情感表达模块"，不是核心玩法；且它由上市游戏公司 ESG 团队供养，非社区/开源模式。
3. **数字疗法赛道热但方向不同**：获批产品集中在**筛查/辅助诊断**（ALSOLIFE 爱守医生）与 ADHD（数药智能），孤独症干预类多在临床试验或"评估闭环"阶段（海南先行区）；面向儿童的**干预型游戏**几乎没有拿证者，开星果则绑定脑机接口硬件。
4. **结论**：国内"4–8 岁 ASD 情绪识别的免费功能游戏"是实打实的空白；最近的竞品《星星生活乐园》恰好证明了"免费功能游戏 + 家长口碑 + 全国覆盖"这条路走得通。

### 3.5 开源扫描结论（回答问题 A）

- **没有可整体复用的核心玩法项目**——不必担心重复造轮子，轮子根本不存在；反而应尽早以清晰 License + 文档开源，占据"ASD 情绪功能游戏"生态位。
- **可直接复用**：素材层（OpenMoji/Twemoji/Mulberry/ARASAAC）+ 标准层（OBF）。
- **可集成/可贡献**：Cboard、AsTeRICS Grid（二期社交/沟通方向的天然盟友，且都缺中文社区贡献者）。
- **可借鉴**：Emotional-Flash/learnwithroo（闪卡范式）、Bearmax（表达侧）、Autimo（家人照片自定义）、Antura（工程与本地化）。
- **国内开源同样空白**：中文检索 93 库中与 ASD 相关者均为个位数星标的毕业设计/停更项目。

| 死亡产品 | 死因 | 星屿的规避动作 |
|---|---|---|
| Mind Reading（2003–约2012） | **载体绑定**：DVD/CD-ROM 随操作系统演进自然死亡（[停售页](https://www.angusrobertson.com.au/books/mind-reading-the-interactive-guide-to-emotions-dvd-not-suitable-for-apple-lion-operating-system-and-above-simon-baron-cohen/p/9781843105596)） | Web/跨平台优先，构建链保持可复现，开源保证"任何人可重新编译" |
| Look At Me（2014–约2016） | **依附单一厂商的 CSR 营销周期**，活动结束即弃（[TechCrunch](https://techcrunch.com/2014/12/22/samsung-lookatme/)） | 不把存续押在任何单一赞助方；开源+社区是"退出保险" |
| Akili/EndeavorRx（$1B→$34M） | **重监管处方模式**：FDA 认证≠支付方埋单，营收峰值仅 $53.8 万/年（[MedTech Dive](https://www.medtechdive.com/news/akili-sell-34m-virtual-therapeutics-digital/717570/)） | 坚持"辅助训练工具"定位，不宣称疗效、不入医疗器械监管深水区 |
| LetMeTalk（2013–2021） | **单点维护的免费应用**：捐赠制+单开发者，停更 4 年后下架（[AppBrain](https://www.appbrain.com/app/letmetalk-free-aac-talker/de.appnotize.letmetalk)）——**与星屿画像最像的镜子** | 从第一天按开源社区项目运营：清晰 License、贡献指南、低门槛技术栈，让项目可被他人接续（对照组：Cboard 至今活跃） |
| FaceSay / EmotiPlay（冻结） | **学术产品缺增长引擎**：证据一流但无分发渠道与迭代资源 | 证据感≠增长；提前设计分发（开源社区、家长社群、机构/残联合作），小步快迭代 |
| GitHub 学生原型群（全灭） | **无 License、无文档、无用户**的"开源" | 开源≠传代码：License+README+可运行 Demo+Issue 响应缺一不可 |

### 4.4 一句话总结

星屿要做的事——**免费、开源、中文、4–8 岁、情绪识别与表达为核心玩法、内置泛化机制**——在国际、国内、开源三个战场上均无占位者；最强的循证蓝本（Transporters/EmotiPlay 的课程结构）与最好的基础设施（开放图符库、AAC 生态、Antura 工程范式）都已免费摆在桌上，缺的只是把它们组装成"真正好玩的游戏"的人。
