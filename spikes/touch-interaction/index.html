星屿 spike：触摸交互验证（DOM + CSS 方案）

目的：验证不用游戏引擎、纯 DOM + CSS 动画能否满足"认表情"玩法的触摸体验。请在家用平板/手机浏览器打开本页，逐项体验并看底部清单。

日志：

真机检查清单（平板 + 手机各过一遍）

  • [ ] 点卡片：按下有即时缩放反馈，无可感知延迟（<100ms 观感）
  • [ ] 快速连点、双指同点：无双击放大、无页面缩放/滚动窜动
  • [ ] 选中动画（光晕扩散）流畅不掉帧；星星逐颗点亮
  • [ ] 开声音后点卡片有温和提示音（iOS 需先点过"声音"按钮一次）
  • [ ] 系统开启"减弱动态效果"后，动画自动消失、功能不受影响
  • [ ] 横竖屏切换布局不破；日志区显示的 pointerdown→响应耗时 < 50ms
